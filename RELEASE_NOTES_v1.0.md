# v1.0 — Build Your Own Giant Slogans

Download **SloganGenerator-v1.0-windows-x64.zip**, extract the entire archive, then run `SloganGenerator.exe`. No Python installation required; keep `_internal` beside the EXE.

The Steam Workshop item contains 18 example buildings only. Download this generator to create custom buildings from text, fonts or images.

## New in 1.0

- Image import, crop, perspective correction, colour/threshold extraction, eyedropper and manual repair tools.
- Letter pieces with live layout, rotation, scaling, multiselection, alignment and equal spacing.
- Multiline/vertical text, adjustable line/column spacing and custom building names.
- Live 3D preview, three base styles, adjustable weathering and rendered thumbnails.
- Full projects with editable pieces, appearance settings, autosave and recovery. Only the current 1.0 project format is supported.
- One-click local game installation with file verification and no overwriting of existing buildings.
- All 18 interface languages across text, image, layout and 3D windows.

Download about 48 MB; extracted application about 105 MB (below the 400 MB budget).

## Notes

Restart the game after installing buildings. Text is fixed geometry; editing content requires generating a new building. Installed font coverage determines available characters; font files are not bundled. Image extraction may need manual cleanup. Preview lighting differs from the game. OS dialogs use the Windows language; raw technical errors may retain library wording. Installation is local and does not upload to Steam.
